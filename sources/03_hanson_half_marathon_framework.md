# Hanson Half-Marathon Framework

## Default Framework

Use Hanson / Hansons Method principles as the default framework for the current cycle, adapted to the half marathon rather than copied from Advanced Hansons Marathon Method.

## Emphasis

- Cumulative fatigue
- Moderate long runs
- Consistent frequency
- Threshold, stamina, and half-marathon-pace work
- Easy days kept genuinely easy

## SOS Structure

The plan may use structured SOS days, but load should be earned through consistency and recovery signals.

## Last-Rep Rule (operator override, 2026-10-01)

On SOS workout days the operator may run the last rep fast ("last one fast
one") when feeling good, with no pace cap. The Hansons' standard guidance is
to hold prescribed pace and not run workouts faster; the operator has chosen
to deviate from that on the final rep. Written paces in the week files stay
as the targets for the remaining reps. Record: `decisions/2026-10-01_last_rep_fast_override.md`.
